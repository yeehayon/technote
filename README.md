# technote

AI 에이전트 하네스 엔지니어링, 에이전트 설정(스킬 · MCP · AGENTS.md), 에이전트 장시간 · 무인 운영에 대한 기술 노트입니다.

**보기:** https://yeehayon.github.io/technote/

- `docs/notes/<테마>/` : 요청해서 조사한 글
- `docs/briefing/` : 정기 자동 작성 글
- `templates/` : 글 양식

로컬 미리보기: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/mkdocs serve`
